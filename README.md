# Mesonova — air-launched sounding rocket for mesospheric measurements

```
assignment.md        the assignment, verbatim — source of truth, do not edit
deliverables/        what we show, one folder per project phase (pm1/, ...)
meetings/            one file per meeting: team, decisions, actions
sources/             the colleagues' drive snapshots, converted to Markdown
tools/               scripts that generate the derived files
```

Four remarks:

- **Every fact has one home.** The team and the decisions live in `meetings/`; the requirement set
  lives in `deliverables/`. Everything else refers to them instead of repeating them.
- **`sources/` is generated.** `tools/convert-drive.py` produces it from the colleagues' drive
  snapshot; it is never edited by hand.
- **Numbers carry a tier:** S primary source · A strong secondary · B plausible, unverified ·
  C tentative.
